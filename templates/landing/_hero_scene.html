{% comment %} Hero scene for the public landing page. The scene is split into four SVG layers so the landing script can move each layer at its own speed (scroll parallax + a subtle pointer offset). Every layer shares the same viewBox and `preserveAspectRatio="xMidYMax slice"`, so they stay aligned at any viewport size. `data-speed` values are read by static/js/landing.js (1 = moves with the page, < 1 = distant, > 1 = foreground). Daylight palette: it is a school, so the scene stays bright and welcoming. {% endcomment %}
